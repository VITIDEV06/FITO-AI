# Reglas de UI

La UI de FITOAI debe ser simple, rápida y útil en campo.

## Principios

- clara en móviles,
- legible sin esfuerzo,
- prioriza la acción principal,
- no añade decoraciones innecesarias,
- comunica claramente si la IA es local.

## Flujo principal

1. usuario escribe observación,
2. puede añadir cultivo,
3. lanza análisis,
4. revisa resultados,
5. consulta historial local.

## Resultado esperado

Mostrar:

- cultivo,
- síntomas,
- posibles causas,
- nivel de certidumbre,
- próximos pasos,
- información faltante.

## Indicador de estado

Debe quedar visible que la inferencia se ejecuta localmente mediante QVAC.
